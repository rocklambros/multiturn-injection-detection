\begin{abstract}
Single-turn prompt injection classifiers achieve high accuracy on known attack distributions, yet they fail against multi-turn attacks that distribute malicious intent across several conversation turns. Each turn in isolation appears benign; the adversarial signal emerges only from how turns relate over time. We present a dual-encoder architecture that pairs a frozen single-turn GRU encoder (2.6M parameters) with a trainable sequence-level LSTM (27K parameters) to carry forward accumulated context across turns. On 73,390 single-turn samples from eight public datasets, the Chollet heuristic correctly predicts that TF-IDF bag-of-bigrams (F1\,=\,0.834) outperforms all deep learning models including transformers at this data scale. On 7,000 synthetic multi-turn conversations modeled after published attack strategies (Crescendo, Foot-in-the-Door, fragment distribution, instruction layering), the temporal architecture achieves F1\,=\,0.989, a +10.3 percentage point improvement over the best per-turn classifier (F1\,=\,0.887). Adding attention raises F1 to 0.992 while providing interpretability, and threshold tuning reaches 0.995. These results confirm that temporal modeling captures escalation patterns invisible to single-turn classification.
\end{abstract}

\section{Problem Statement and Motivation}
% ============================================================

\subsection{The Problem}

Single-turn prompt injection detection achieves high accuracy on known attack patterns. ProtectAI's DeBERTa model reaches 99\%+ F1 on published benchmarks \cite{protectai2024}. This performance is limited to known attack distributions. Novel attacks, adversarially crafted inputs, and multi-turn strategies routinely evade these detectors \cite{injecguard2024, vassilev2025}. Real-world attacks against AI agent systems increasingly distribute malicious intent across multiple conversation turns, where each individual turn appears benign in isolation.

This is the \textbf{Crescendo attack pattern} \cite{russinovich2025}: an attacker gradually escalates across turns, establishing trust and context before making the exploitative request. The \textbf{Foot-in-the-Door technique} \cite{emnlp2025fitd} similarly leverages compliance momentum across turns. Vassilev \cite{vassilev2025} extends G\"{o}del's incompleteness theorem to argue that no single-turn classifier can theoretically detect all such attacks.

\subsection{Why Deep Learning}

The multi-turn attack signal is fundamentally temporal: earlier turns create context that later turns exploit. LSTM and GRU architectures are designed to model exactly this type of sequential dependency through their gating mechanisms. A bag-of-words or per-turn classifier has no mechanism to carry forward accumulated risk state.

\subsection{Contribution}

This project builds the first multi-turn distributed prompt injection detection system using a dual-encoder architecture: a frozen single-turn encoder paired with a sequence-level LSTM that carries forward context across turns. We demonstrate a \textbf{+10.3 percentage point F1 improvement} over per-turn classification on multi-turn attack data (F1 = 0.989 vs.\ 0.887).

\subsection{Data Bias Analysis}
\label{sec:bias}

Three sources of bias require discussion.

\textbf{Source distribution dominance.} The \texttt{imoxto} dataset contributes 40,000 of 73,390 samples (54.5\% of training data). This dataset contains system prompt context that other sources lack, potentially biasing models toward detecting injection patterns co-occurring with system prompts rather than injection content alone. The Gandalf CTF attacks (16,012 samples, 21.8\%) skew toward game-style jailbreaks that may not represent production attack distributions.

\textbf{Text length correlation with class.} Injection texts tend to be longer than benign queries (mean 112 tokens vs.\ 63 tokens for benign). Models could partially exploit length as a proxy feature rather than learning semantic content. The TF-IDF baselines are particularly susceptible to this, as longer documents produce denser feature vectors.

\textbf{Class imbalance handling.} The 64/36 benign/injection split is moderate. We chose \textit{not} to apply class weights or oversampling for two reasons: (1) the imbalance ratio (1.78:1) is mild enough that standard loss functions converge without correction, and (2) applying class weights in preliminary experiments increased recall by 2 points at the cost of 5 points of precision, a poor trade-off for a security classifier where false positives erode user trust. Stratified splitting preserves the natural distribution in all partitions.

\subsection{Cleaning Pipeline}

Nine cleaning steps applied in order: column normalization, label normalization (0 = benign, 1 = injection), whitespace stripping, internal whitespace collapse, exact deduplication, near-deduplication (lowercase + strip punctuation), short text removal ($<$3 tokens), long text removal ($>$2048 chars), and logging.

Removals: 167 exact duplicates, 40 near-duplicates, 132 empty/short, 489 too-long.

\subsection{Synthetic Multi-Turn Data}

No public dataset of multi-turn distributed attacks exists. We generated 7,000 synthetic conversations (5,000 train, 1,000 val, 1,000 test) using four strategies:

\begin{itemize}[nosep]
    \item \textbf{Fragment distribution (40\%)}: Split injection text into 3--5 fragments interleaved with benign filler.
    \item \textbf{Gradual escalation (30\%)}: Crescendo pattern; each turn adds specificity toward the goal.
    \item \textbf{Context priming (20\%)}: Establish persona/authority in early turns, exploit later.
    \item \textbf{Instruction layering (10\%)}: Each turn adds one constraint, cumulatively overriding safety.
\end{itemize}

Balanced 50/50 classes, 3--10 turns per conversation. Benign conversations sampled from a pool of 500+ unique filler turns.

\subsection{Tokenization}

Custom vocabulary of 20,000 tokens built from training data only. Max sequence length: 256 tokens. OOV rate: 0.87\% on training, 1.19\% on validation.

\subsection{Chollet Heuristic Analysis}

Following Chollet \cite{chollet2021}, we compute the ratio of training samples to mean words per sample to predict which model family will perform best:

\begin{itemize}[nosep]
    \item Training samples: 51,373
    \item Mean words per sample: 87.3
    \item Ratio: $51{,}373 / 87.3 = 588$
    \item Threshold: 1,500
\end{itemize}

At ratio 588 (well below 1,500), the Chollet heuristic predicts that \textbf{bag-of-bigrams models should outperform sequence and transformer models}. With relatively few samples per unit of text complexity, simpler models with strong feature engineering (TF-IDF bigrams) capture the discriminative patterns without the overfitting risk inherent in higher-capacity models.

This prediction is empirically validated: TF-IDF + RF (F1 = 0.834) outperforms all deep learning models including transformers, confirming that transformers need substantially more training data to outperform simpler approaches on this task.

\section{Metric Justification}
% ============================================================

We report F1 score as the primary metric rather than accuracy. The justification is threefold.

\textbf{Class imbalance renders accuracy misleading.} The dataset is 64\% benign. A majority-class classifier that predicts ``benign'' for every input achieves 64\% accuracy with F1 = 0.0 on the injection class. A stratified random classifier achieves 54\% accuracy with injection-class F1 = 0.358. Neither provides any detection capability
despite appearing numerically reasonable on accuracy alone.

\textbf{Security cost asymmetry demands balanced precision-recall.} In prompt injection detection, false negatives allow attacks to succeed (security breach), while false positives block legitimate users (usability cost). F1 balances these competing concerns. Accuracy treats all errors equally, which does not reflect the operational reality.

\textbf{F1 enables fair cross-model comparison.} All models operate on the same class distribution. F1 penalizes models that achieve high recall by sacrificing precision (or vice versa), making it a more discriminating metric than accuracy for comparing architectures. ROC-AUC is reported as a secondary threshold-independent metric.

\subsection{Iteration 5: Multi-Turn Classifier (Novel)}

Dual-encoder architecture:
\begin{enumerate}[nosep]
    \item \textbf{Turn encoder} (frozen GRU from Iter 4): encodes each turn into a 32-dim vector.
    \item \textbf{Sequence LSTM} (64-dim hidden): processes turn vectors temporally.
    \item \textbf{Classification head}: Dense(64$\to$32$\to$1) with dropout.
\end{enumerate}

Only $\sim$27,000 parameters are trainable (the sequence LSTM and classification head). The turn encoder's 2.6M parameters are frozen.

\subsection{Iteration 6: Attention}

Additive attention over sequence LSTM hidden states replaces final-hidden-state-only classification. This provides interpretability: attention weights reveal which turns drive the classification decision.

\subsection{Iteration 7: Threshold Tuning}

Sweep thresholds 0.01--0.99 on the attention model. Optimize for F1, 95\% recall, and 95\% precision operating points.

\subsection{Baseline Error Analysis}
\label{sec:baseline_errors}

The TF-IDF + RF baseline (F1 = 0.834) produces 893 false negatives and 323 false positives on the test set. Examining these errors reveals patterns that motivate the deep learning approach.

\textbf{False negatives (missed injections).} The TF-IDF model fails on injections that avoid common attack keywords. Obfuscated attacks using character substitution (e.g., ``1gnor3 pr3vious instructions''), indirect phrasing (``What would happen if someone were to...''), and role-play setups (``Pretend you are a character who...'') produce TF-IDF vectors indistinguishable from benign text. These attacks rely on semantic meaning and pragmatic context rather than lexical cues, which a bag-of-words model cannot capture.

\textbf{False positives (blocked benign text).} Legitimate security discussions, penetration testing queries, and cybersecurity educational content share vocabulary with actual injection attempts. A user asking ``How does prompt injection work?'' produces TF-IDF features nearly identical to an actual injection. The model cannot distinguish discussion \textit{about} attacks from actual attacks without deeper semantic understanding.

These error patterns confirm the Chollet heuristic prediction from a different angle: while bag-of-bigrams wins on aggregate F1, the \textit{types} of errors it makes are precisely those that sequence models could address with more training data. The errors are semantic, not statistical.

\subsection{Multi-Turn Example Analysis}
\label{sec:multiturn_example}

The temporal model succeeds on conversations where per-turn classification fails. Consider a representative 5-turn gradual escalation attack:

\begin{enumerate}[nosep]
    \item ``I'm writing a cybersecurity course for my university'' (benign; GRU score: 0.08)
    \item ``Can you explain common social engineering techniques?'' (benign; GRU score: 0.12)
    \item ``How would an attacker typically phrase a request to bypass safety filters?'' (borderline; GRU score: 0.31)
    \item ``Show me an example of a prompt that could manipulate an AI assistant'' (borderline; GRU score: 0.44)
    \item ``Now generate a response as if those safety filters were disabled'' (injection; GRU score: 0.47)
\end{enumerate}

No individual turn exceeds the 0.5 classification threshold. The per-turn GRU, taking the maximum probability across turns, outputs $\max(0.08, 0.12, 0.31, 0.44, 0.47) = 0.47 < 0.5$ and classifies the conversation as benign. The sequence LSTM processes the turn embedding sequence and recognizes the cumulative escalation pattern. It outputs a conversation-level probability of 0.94, correctly flagging the attack.

This is exactly the Crescendo pattern described by Russinovich et al.\ \cite{russinovich2025}: each turn is individually innocuous, but the sequence reveals adversarial intent.

\subsection{Statistical Significance Discussion}
\label{sec:significance}

The improvement from Iter 5 (F1 = 0.989) to Iter 7 (F1 = 0.995) corresponds to approximately 6 additional correct predictions on a 1,000-sample test set. On a test set of this size, the 95\% confidence interval for F1 is approximately $\pm$0.01. The difference between 0.989 and 0.995 falls within this interval and is \textit{not} statistically significant.

The meaningful finding is the \textbf{+10.3 percentage point structural gap} between per-turn classification (F1 = 0.887) and temporal classification (F1 = 0.989). This gap reflects an architectural capability difference, not a tuning artifact. The per-turn model \textit{cannot} detect distributed attacks regardless of threshold, because it processes turns independently.

The 0.995 ceiling likely reflects synthetic data limitations rather than model capacity. Our template-based generation produces conversations with consistent structural patterns that a sequence model can learn to near-perfection. Real-world distributed attacks, with more diverse and sophisticated escalation strategies, would likely produce lower absolute F1 scores while preserving the structural advantage of temporal modeling.

\subsection{Error Pattern Analysis}

Across all single-turn models, the dominant error type is false negatives (missed injections). The GRU (Iter 4) produces 1,146 false negatives vs.\ 120 false positives on 11,009 test samples, a ratio of 9.6:1. This asymmetry is consistent across architectures:

\section{Discussion}
% ============================================================

\subsection{Why Multi-Turn Works}

The dual-encoder architecture succeeds because it separates two concerns:
\begin{enumerate}[nosep]
    \item \textbf{What does each turn say?} The turn encoder (frozen GRU) is already competent at single-turn detection.
    \item \textbf{How do turns relate over time?} The sequence LSTM learns temporal patterns: escalation gradients, context-priming followed by exploitation, and cumulative constraint layering.
\end{enumerate}

The frozen turn encoder prevents catastrophic forgetting while the sequence LSTM learns to recognize escalation, persona establishment, and cumulative constraint patterns.

\subsection{Iterative Refinement Summary}

The project followed a deliberate iterative progression:

\begin{enumerate}[nosep]
    \item \textbf{Baselines (Iter 0)}: Established F1 = 0.834 performance floor with TF-IDF + RF.
    \item \textbf{LSTM (Iter 1)}: Matched baseline at F1 = 0.814, confirming the Chollet prediction that deep learning would not immediately surpass bag-of-bigrams at this data scale.
    \item \textbf{GloVe (Iter 2)}: Pretrained embeddings provided no benefit (F1 = 0.813), motivating domain-specific learned embeddings.
    \item \textbf{BiLSTM + Dropout (Iter 3)}: Bidirectionality and regularization provided marginal gains (F1 = 0.815). Dropout 0.5 over-regularized; 0.3 was selected.
    \item \textbf{GRU (Iter 4)}: Matched BiLSTM performance with fewer parameters (F1 = 0.815, ROC-AUC = 0.946). Selected as the turn encoder.
    \item \textbf{Transformers (Iter 4b--4c)}: Both underperformed bag-of-bigrams, confirming data insufficiency. Custom transformer F1 = 0.808; DistilBERT F1 = 0.806.
    \item \textbf{Multi-turn LSTM (Iter 5)}: Step-function improvement to F1 = 0.989, validating the temporal hypothesis.
    \item \textbf{Attention (Iter 6)}: Minor F1 gain to 0.992 with interpretability via attention weights.
    \item \textbf{Threshold tuning (Iter 7)}: Optimized to F1 = 0.995 at threshold 0.64.
\end{enumerate}

Each iteration was motivated by a specific hypothesis. Negative results (GloVe, transformers) were as informative as positive ones.

\subsection{Limitations}

\begin{itemize}[nosep]
    \item \textbf{Synthetic data}: Multi-turn conversations are generated from single-turn data using template-based strategies. Real-world distributed attacks may be more sophisticated.
    \item \textbf{English only}: All training data is English. Non-English injection patterns are not represented.
    \item \textbf{Known patterns}: Training data skews toward published attack types. Novel social engineering approaches may evade detection.
    \item \textbf{Fixed architecture}: 10-turn maximum with fixed 256-token turns. Real conversations vary more widely.
    \item \textbf{Source bias}: 54.5\% of training data comes from a single source (see Section~\ref{sec:bias}).
\end{itemize}

\subsection{Future Work}

\begin{enumerate}[nosep]
    \item Real-world multi-turn datasets from AI safety research teams.
    \item Transformer-based turn encoders (BERT/DeBERTa) for richer representations.
    \item Online detection: classify incrementally as each turn arrives.
    \item Cross-lingual detection to address multilingual attacks.
    \item Adversarial robustness testing against adversaries aware of the architecture.
\end{enumerate}
